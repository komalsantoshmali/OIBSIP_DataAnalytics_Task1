# Retail Sales Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to understand customer demographics, sales trends, product category performance, and relationships between numerical variables.

## Dataset

The dataset contains **1,000 retail transactions** with the following information:

* Transaction ID
* Date
* Customer ID
* Gender
* Age
* Product Category
* Quantity
* Price per Unit
* Total Amount

## Analysis Performed

The following analyses were performed:

1. Checked dataset structure and data types.
2. Checked for missing values.
3. Calculated mean, median, mode, and standard deviation.
4. Analyzed monthly and quarterly sales trends.
5. Analyzed sales by customer age groups.
6. Compared sales by gender.
7. Analyzed revenue by product category.
8. Created a correlation heatmap.
9. Analyzed customer age distribution.
10. Added observations and business recommendations.

## Key Insights

* The **46–55 age group** generated the highest sales.
* **Electronics** generated the highest revenue among the product categories.
* Female customers generated slightly higher total sales than male customers.
* The fourth quarter showed strong sales performance.
* The dataset contains product categories but does not contain individual product names, so product-level analysis was not possible.

The analysis provides useful insights into customer behavior, sales trends, and category-level revenue. These insights can help businesses identify strong customer segments, focus on high-performing product categories, and plan promotions during stronger sales periods.
